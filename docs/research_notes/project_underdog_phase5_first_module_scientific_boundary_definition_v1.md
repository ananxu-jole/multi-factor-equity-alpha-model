## 1. Executive Scientific Classification

Final classification: `FIRST_PHASE5_MODULE_BOUNDARY_DEFINED_WITH_OPEN_GAPS`

This note defines the scientific boundary of the first empirical module that may eventually follow Project Underdog Phase 5 scientific work. The broad selected hypothesis, `Peer-Relative Post-Stress Repair And Stabilization Asymmetry`, is too wide to enter measurement or formula design as a single unit. It combines peer comparison, post-stress repair, stabilization, asymmetry, and common-versus-idiosyncratic decomposition. The first module must therefore be narrowed to the smallest scientifically defensible claim.

This classification applies only to the module boundary. It does not imply measurement readiness, formula readiness, implementation readiness, peer readiness, source readiness, empirical support, validation readiness, production readiness, or ML readiness.

## 4. Exactly One Selected First-Module Boundary

Selected first module:

`Common-Versus-Idiosyncratic Post-Stress Repair Decomposition`

One-sentence scientific claim:

Under a pre-defined post-stress context, historically valid economic-peer behavior may help distinguish the common component of observed own-security repair from the security-specific component.

Scientific purpose:

Determine whether peer context changes the interpretation of post-stress repair by separating common recovery from security-specific repair, before asking whether that distinction creates alpha, asymmetry, stabilization, persistence, or transition-order information.

Primary information role:

`COMMON_IDIOSYNCRATIC_DECOMPOSITION_INFORMATION`

Current evidence maturity:

`HYPOTHESIS_DEFINED` and `BLOCKED_PENDING_EXTERNAL_EVIDENCE`

This name intentionally does not imply empirical approval.

## 5. Single Primary Scientific Claim

Primary claim:

Under a pre-defined post-stress context, historically valid economic-peer behavior may help distinguish the common component of observed own-security repair from the security-specific component.

This is the only primary claim. It does not assert predictive incrementality, alpha validity, formula readiness, or peer readiness.

## 6. Permitted Secondary Questions

Secondary questions may support interpretation but must not become independent first-module objectives:

- Does peer-common recovery explain part of observed own-security repair?
- Is the remaining security-specific component scientifically interpretable after market and existing repair-family controls?
- Does peer context change the interpretation of existing hostile/stress repair evidence?
- Can the peer comparator add explanatory value even if predictive incrementality is not established?

These questions are bounded to interpretation. They must not become separate stabilization, asymmetry, ranking, persistence, or liquidity modules inside the first module.

## 9. Stabilization Boundary

Leading conceptual treatment: `CONFOUNDER`

Stabilization is not indispensable to first-module repair decomposition. It may describe a consequence of repair, but it also overlaps existing volatility-compression and VoV evidence. Within the first module, stabilization should be treated as a confounder and control reference. If stabilization later proves scientifically distinct from repair and volatility normalization, it should become a separate future module.

No stabilization measurements are defined.

## 10. Asymmetry Boundary

Leading conceptual treatment: `LATER_BOUNDED_EXTENSION`

Positive-versus-negative asymmetry is not part of the first primary mechanism. The first module should determine whether peer context can decompose post-stress repair at all. Only after that boundary is scientifically meaningful should Project Underdog ask whether positive repair, negative failure-to-recover, or asymmetry between them forms a separate module.

No signs, thresholds, or directional rules are defined.

## 13. Relationship To Existing Repair Families

Leading current relationship:

`DECOMPOSITION_OF_EXISTING_REPAIR_EVIDENCE`

The module asks whether observed post-stress repair is common to valid peers or specific to the security. This directly interprets the strongest existing repair evidence rather than starting as a new alpha family.

Strongest alternative:

`EXISTING_REPAIR_FAMILY_REFINEMENT`

If future evidence shows peer context only narrows when existing repair works, without adding distinct common-versus-idiosyncratic interpretation, the module should be treated as a repair-family refinement.

Future evidence distinguishing them:

- decomposition is supported if valid peers explain a common component while leaving a coherent security-specific component;
- refinement is supported if peer context only restricts the existing repair family without changing scientific interpretation;
- rejection is required if peer context adds no meaning beyond own repair, market state, or invalid peer construction.

## 14. Boundary Against Volatility Compression

Repair belongs to the first module only as recovery from a pre-defined post-stress context and as the object being decomposed into common and security-specific components.

Stabilization belongs outside the first module when it means volatility normalization, reduced disorder, or compression of realized volatility.

Volatility compression remains a confounder and control reference. If future work asks whether peer context decomposes volatility normalization, that should be a separate stabilization or volatility module.

## 15. Boundary Against Participation And Liquidity

Participation and liquidity should be treated as controls and contamination risks for the first module.

They may later support:

- participation/liquidity decomposition;
- peer-wide liquidity-stress interpretation;
- trading-intensity recovery context;
- size or liquidity comparability controls.

They should not be embedded as first-module mechanisms because Project Underdog already has participation and liquidity evidence, and folding them into repair decomposition would create avoidable redundancy.

## 16. Boundary Against Persistence, Rank, And Transition Timing

The first module must not become:

- peer-relative rank recovery;
- post-stress persistence;
- leadership emergence;
- transition-order research.

Persistence and rank families already have conditional evidence and overlap risks. Transition timing can relabel repair entry or exit. Leadership language is especially constrained by Non-Hostile Leadership Rotation negative evidence. Any future leadership or transition-order claim must be a separate bounded hypothesis with explicit comparison to parked leadership results.

## 17. Boundary Against Macroeconomic Context

Macroeconomic context is scientifically important but excluded from the first module.

Macro regimes may later help interpret:

- common stress;
- common recovery;
- monetary conditions;
- credit conditions;
- inflation conditions;
- broad risk environments.

Current treatment:

`RESERVED_AS_FUTURE_CONDITIONING_WORKSTREAM`

Macro context is not required to state the first claim. Adding it now would expand the module from peer repair decomposition into broad regime-conditioned economic research. No macro variables are designed, selected, or obtained.

## 20. Boundary Failure Conditions

The proposed boundary fails if:

- multiple co-equal mechanisms are included;
- repair and stabilization cannot be distinguished conceptually;
- asymmetry is needed only after seeing results;
- participation or liquidity dependence is hidden inside repair;
- rank or transition dependence is hidden inside repair;
- comparator role is undefined;
- alpha information and contextual information are conflated;
- governance information is treated as predictive input;
- contextual conditioning expands beyond the core claim;
- macro context becomes required despite not being present in the primary claim;
- no falsifiable distinction exists from existing repair families;
- valid peer context cannot be defined independently of current/static metadata;
- the module cannot fail closed when peer authority, identity, or time safety is absent.
