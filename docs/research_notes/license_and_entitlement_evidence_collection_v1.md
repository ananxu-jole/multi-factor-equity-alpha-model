## 7. Known-Date And Publication-Date Evidence Requirements

Conceptual date vocabulary:

- Observation date: date the underlying economic or market state refers to.
- Effective date: date a classification, ticker, listing, event, or link is stated to become effective.
- Announcement date: date an event was announced.
- Source publication date: date the source published a record.
- Source availability date: date the record became available to the project through the source channel.
- Ingestion date: date the project collected or froze the record.
- Revision date: date the source changed a prior record.
- Restatement date: date a prior value was restated.
- Event date: date an event occurred or is recorded as occurring.
- Listing date: date a security began listing or active eligibility.
- Delisting date: date a security ceased listing or active eligibility.
- Classification-start date: start of classification validity.
- Classification-end date: end of classification validity.
- Project-known date: earliest date the project is allowed to treat the record as known for signal construction.
